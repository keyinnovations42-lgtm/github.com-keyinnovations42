# Key Innovations

**Independent software development — Marion, Ohio**

This repository hosts the official homepage for [Key Innovations](https://key-innovations.com), an independent software development operation building secure, interconnected digital tools.

## What We Build

- **KI Platform** — Corporate infrastructure with live payment processing and unified admin dashboard
- **CyberGuard** — AI-powered parental control system with real-time content filtering and monitoring
- **NFC Transfer** — End-to-end encrypted data transfer for phone-to-phone and card-to-phone communication

## Ecosystem

All three applications share a unified identity layer built on the Internet Computer Protocol (ICP) with Internet Identity — passwordless, decentralized authentication you control.
